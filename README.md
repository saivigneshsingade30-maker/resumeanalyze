# 📄 AI Resume Analyzer & ATS Optimizer

An AI-powered Resume Analyzer and ATS (Applicant Tracking System) Optimizer built using **Python and Streamlit**.

This project helps job seekers analyze their resumes against a specific job description and identify missing keywords, skills, and areas for improvement.

## 📌 Features

- 📄 Upload Resume in PDF or DOCX format
- 🎯 Calculate ATS Compatibility Score
- 🔑 Calculate Job Description Keyword Match
- 🛠️ Detect Technical Skills
- 🔍 Identify Missing Job-Related Keywords
- 📧 Extract Email Address
- 📱 Extract Phone Number
- 💡 Generate Resume Improvement Suggestions
- 📊 Display ATS Score with Progress Bar
- 🌐 Web-based interface using Streamlit
